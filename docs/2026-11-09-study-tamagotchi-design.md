# 학습 다마고치 설계 문서

- 작성일: 2026-11-09
- 과목: 건양대 교양 "인공지능이해와실천" 팀 프로젝트 (바이브 코딩)
- 마감: 2026-11-17 ~ 11-24

## 한 줄 요약

초등 저학년이 그림 고르기 문제를 풀어 단원을 마스터할 때마다 별을 받고, 별이 쌓이면 캐릭터가 자라는 웹 학습 프로그램.

## 대상과 과목

- 대상: 초등 1~3학년
- 과목 3개 × 단원 3개 × 문제 5개 = 45문제
  - 영어: 동물, 색깔, 과일
  - 바른 생활: 인사, 양보와 배려, 정리 정돈
  - 우리 동네: 직업, 공공장소, 교통 안전

## 흐름

1. 알: 캐릭터 이름 짓기
2. 홈: 캐릭터, 별 개수, 과목 버튼 3개, 기록 보기
3. 과목: 단원 3개. 앞 단원을 마스터해야 다음 단원이 열린다
4. 단원: 5문제 → 결과 → 홈

### 문제

- 문제를 자동으로 읽어준다 (speechSynthesis, 영어는 en-US, 나머지 ko-KR, 속도 0.85). 🔊 다시 듣기 버튼.
- 그림 보기 3개 중 터치. 문제 순서와 보기 순서는 매번 섞는다.
- 정답: 캐릭터 기쁨 + "딩동댕!"
- 오답: 한 번 더 기회. 두 번째도 틀리면 정답을 보여주고 다음 문제로.

### 마스터와 성장

- 5문제 중 첫 시도 정답 4개 이상 → 마스터, 별 1개 (단원당 최대 1개)
- 실패 문구는 쓰지 않는다: "거의 다 왔어! 다시 도전!"
- 보상: 단원마다 도감 친구 1마리(content.js의 friend). 마스터하면 획득 카드 + 도감 등록. 도감 화면 3×3, 못 모은 칸은 ❓
- 단계: 도감 친구 0 = 알, 전체의 1/3 미만 = 아기, 전부 미만 = 어린이, 전부 = 어른(축하 화면)
- 2026-11-09 추가: 국어·수학·계절·과학 (단원 = 1·2·3학년 순, 활동지 문항을 고르기형으로 변환). 총 6과목 18단원
- 2026-11-09 추가: 도형·공간 (모양 알기 → 변·꼭짓점·규칙 → 돌리기·뒤집기). 총 7과목 21단원
- 캐릭터는 슬퍼하거나 아프지 않는다. 표정은 idle, happy 2종.

### 기록 보기 (부모님·선생님용)

단원별 별 여부, 최고 점수(첫 시도 정답 수/5), 도전 횟수 표.

## 기술 구조

빌드 없는 정적 웹페이지, 외부 라이브러리 없음.

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 큰 글씨·큰 버튼, 폰·태블릿 겸용 |
| `content.js` | 과목·단원·문제, 캐릭터 이모지 (팀원 수정용) |
| `logic.js` | 순수 함수: 섞기, 퀴즈 준비, 마스터 판정, 별·단계, 단원 잠금, 기록 갱신 |
| `game.js` | 화면 전환, 읽어주기, 저장 |
| `tests/logic.test.js` | logic.js + content.js 형식 검사 (`node --test`) |
| `assets/pet/{stage}_{mood}.png` | 캐릭터 그림 (없으면 이모지) |

문제 형식:

```js
{ say: 'Which one is a cat?', lang: 'en',
  choices: [{ pic: '🐶', label: 'dog' }, { pic: '🐱', label: 'cat' }, { pic: '🐰', label: 'rabbit' }],
  answer: 1 }
```

- 저장: localStorage 키 `study-tamagotchi`에 `{ name, records: { [unitId]: { star, best, attempts } } }`. 막힌 환경이면 저장 없이 진행.
- 음성 미지원 기기: 🔊 버튼 숨김, 글자만.
- 배포: GitHub Pages.

## 범위 밖

로그인·서버, 학년별 난이도, 음성 입력, 캐릭터 꾸미기, 과목 추가.

## 추가 (2026-11-09)

- 도형·공간 3학년 단원 = 직접 돌리고 뒤집기 퍼즐(`type: 'puzzle'`). 회색 그림자에 맞게 🔄 돌리기 / ↔️ 뒤집기. 4번 안에 맞추면 첫 시도 정답.
- 문제 바뀜: 단원에 `gen`(add·mul·div·puzzle)이 있으면 풀 때마다 새 문제 5개를 만들어 고정 문제와 섞고 5개 뽑음. 고정 문제가 5개보다 많아도 매번 5개만 뽑음.
- PC용 exe: `desktop/app.py` (pywebview, 창 안에 index.html). 기록은 `%LOCALAPPDATA%\study-tamagotchi`, 포트 41731 고정.
  빌드: `python -m PyInstaller --onefile --windowed --name 학습다마고치 --add-data "index.html;." --add-data "style.css;." --add-data "content.js;." --add-data "logic.js;." --add-data "game.js;." --add-data "sprites.js;." --add-data "dashboard.html;." --add-data "assets;assets" desktop/app.py`

## 방향 변경 (2026-11-09): 어르신 두뇌건강 다마고치

- 대상: 혼자 사는 어르신. 학습 다마고치 + 독거노인 케어 서비스를 합침.
- 매일: 건강 체크(식사·약·물·걷기·잠 네/아니요 + 기분 3단계, 음성 읽기, 크롬·엣지는 말로 대답 가능) → 캐릭터가 같이 밥 먹고 걷는 반응.
- 두뇌 운동: 낱말·셈하기·생활 상식·도형 공간 (쉬움/보통/어려움). 초등 전용 과목(영어·바른 생활·우리 동네) 제거.
- 캐릭터 기분 = 최근 3일 점수(petMood). 성장 = 체크한 날 + 도감 친구 (30이면 어른). 죽거나 아프지 않음.
- 위험 신호(riskLevel, 의학 기준 아님): 3일 이상 체크 없음 = 연락 필요(보호자·대시보드용), 약 2일 연속 거름 또는 기분 나쁨 3일 = 주의(본인 화면에도 안내).
- 보호자에게 보내기: 최근 7일 요약(weekSummary)을 공유 창/클립보드로.
- dashboard.html: 의료진·복지사 화면 시연용, 가상 어르신 10명. 실제 전송 없음.
- 시연: 주소 뒤에 ?demo → '하루 넘기기' 버튼.
- 저장 키 `brain-tamagotchi` (예전 학습 다마고치 기록과 분리).
